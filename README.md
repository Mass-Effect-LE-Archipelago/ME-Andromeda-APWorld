# Mass Effect Andromeda — APWorld and randomizer

Working folder for the Andromeda Archipelago project. Two large folders sit beside this README and are
**reference material, not build output**:

- `Mass Effect Andromeda/` — a full 48.8 GB copy of the Steam game files (vanilla). Used for static extraction.
- `Mass Effect Andromeda Mods/` — the owner's Frosty mod set plus Frosty Tool Suite 1.0.6.3.
  *(The live, launchable install used for playtesting is `C:\Steam\steamapps\common\Mass Effect Andromeda`.)*

Start here: **[docs/PLAN.md](docs/PLAN.md)** for the design and phases,
**[docs/RECON-2026-10-30.md](docs/RECON-2026-10-30.md)** for the evidence behind it.

Nothing in this folder is built or installed yet. Recon was read-only.
