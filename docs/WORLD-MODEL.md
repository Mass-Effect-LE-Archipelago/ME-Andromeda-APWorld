# World model: regions, missions, check families

Everything here is derived from the shipped asset index (`data/asset-names.txt`, 241,004
unique names extracted by `tools/sb_names.py`), not from a wiki.

## Missions are laid out in `game/journals/`

311 journal assets under a readable taxonomy:

| category | count |
| --- | --- |

| `journals/2_heleus` | 60 |
| `journals/1_initiativeops` | 48 |
| `journals/worldevents` | 32 |
| `journals/0_priorityops` | 15 |

Priority-op ids are explicit and ordered: `m0_prologue`, `m1_planetside`, `m1_5_interlude`,
`m2_firstvault`, `m3_exaltation`, `m4_kettflagship`, `m5_remnantcity`, `m7_meridian`,
`m7_5_epilogue`. That gives a clean mission ladder for **mission-access items** and for the
win condition (`m7_meridian`).

## Plot assets: the named check vocabulary

1,147 `game/plots/...` assets. Their taxonomy maps directly onto check families:

- `game/plots/levels/hubs/hub_nexus` (116), `hub_aya` (101), `hub_tempest` (76),
  `hub_kadara` (25) — hub-side quest state
- `game/plots/levels/crit/m1_planetside` (68), `m0_prologue` (11), `m5_5_interlude` (10)
- `game/plots/levels/unc/{storm,des,ice,olw}` — open-world state
- `game/plots/squadmates/{jaal,peebee,cora,vetra,liam,drack}/plotlogic` — squadmate
  availability/trust
- `game/plots/crew/{techofficer,doctor,pilot,scienceofficer}/plotlogic`
- `game/plots/systems/outposts/{outlaw,kett}` — outpost state
- `game/plots/global/{missions,pathfinder,trust,check_*}`, `game/plots/bstory/...`

Leaf names are human-readable, e.g. `check_bothtowersdone`,
`scourge_01_questmarkervisible`, `increment_trackerfound`,
`crit_tempest_0725_meridian_returntocity_available`.

## What this means for the world design

- **Regions** are settled (above), so travel gating is implementable now.
- **Mission access items** come from the priority-op ladder (`m0` … `m7_5`) plus the
  initiative-ops and Heleus side-mission folders.
- **Checks** will be plot flags observed in the save (78,368 GUIDs) joined to these names
  once the container reader resolves GUIDs; the 1,147 named plot assets are the first
  readable tranche, and `check_*` leaves are ideal low-stakes "check slop".
- **Filler** has an obvious home: research points, credits, resources, AVP.

Open dependency: the GUID ↔ name join, which needs the compressed cas data read
(`tools/frostbite/`, in progress — see `docs/FROSTBITE-READER.md` when the subagent lands).
